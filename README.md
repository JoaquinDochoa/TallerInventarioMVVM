# Inventario Taller — base MVVM para DSY1105

## Primer avance académico
Aplicación Android con Kotlin, Jetpack Compose, navegación, Room y MVVM.
Permite ingresar con datos ficticios, registrar, listar, buscar y eliminar productos con confirmación.
Los datos permanecen al cerrar la aplicación.

**Demo:** usuario `admin` y PIN `1234`. El acceso es solo una simulación académica, no autenticación segura.

## Abrir en Android Studio
1. Abre la carpeta `TallerInventarioMVVM` con Android Studio.
2. Configura Gradle JDK 17 y deja que el IDE sincronice las dependencias.
3. Selecciona un emulador Android API 26 o superior.
4. Ejecuta `app`.

Este ZIP no incluye el Gradle Wrapper (puedes generarlo con el Gradle integrado o usar un proyecto nuevo de Android Studio y copiar los archivos).
